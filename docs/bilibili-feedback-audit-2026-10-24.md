# 视频评论诉求与项目实现对照

核查日期：2026-10-24（北京时间）

## 核查范围

- 视频：[Minecraft & 郊狼 forge NeoForge fabric](https://www.bilibili.com/video/BV1ZUfvBkE9F/)。通过 Bilibili 公开接口遍历主评论及楼中楼，取得 **702 条唯一评论：275 条主评论、427 条回复**，与接口计数一致，抓取无错误。
- 需求归并时排除单纯表情、艾特、夸赞和重复发言；作者回复作为历史进度证据，不视作新增用户需求。表中点赞数仅代表对应评论的抓取时快照，不代表需求人数。
- 代码：当前检出 `1.17.1-Fabric`，提交 `54b2df7`；同时核对远端全部 25 个版本分支，SSH `ls-remote` 返回的分支头与本地对应分支一致。通过读取其他分支核查，不切换工作区。
- GitHub：读取 62 个 Release，以及 issues 集合中的全部 25 条记录（其中 19 个 issue、6 个 PR）。截至核查时，唯一未关闭的 issue 为 [#25](https://github.com/bilbillm/DGLab-Craft/issues/25)。
- “已实现”表示已有可达代码或发布附件支持；本次没有启动各版本游戏、连接实体设备或重新验证全部整合包。问题关闭和发布说明是历史证据，不等同于所有环境实测通过。

## 主要结论

已有成果集中在版本移植、连接兜底和早期故障修复。明确未完成的需求包括 App 4.0 适配、自定义波形界面、独立中转程序及部分指定版本。当前最需要处理的是 1.21.11 Fabric 打开界面崩溃，以及不同分支之间的功能和修复差异。

两个容易误判的地方：**波形预览不等于自定义波形**；**某个版本已有下载包不等于该版本已稳定可用**。

## 需要优先处理的缺口

1. **1.21.11 Fabric UI 崩溃。** [#25](https://github.com/bilbillm/DGLab-Craft/issues/25) 于 10 月 18 日创建且仍未关闭。该分支 `MainScreen.render()` 仍显式调用 `renderBackground()`；是否与 26.x 的重复模糊完全同根因，需要针对这一分支核对日志并复现，不能直接套用修复结论。
2. **统一连接兼容信息。** 清楚标注 App 3.x / 4.0、设备代际、MC 与加载器组合及对应 Java。评论中“全部降到 Java 17”的历史经验不能当作所有分支通用方案；1.21.11 的发布说明要求 Java 21，26.x 要求 Java 25。
3. **补齐跨分支修复。** 重点是旧 Forge 的伤害反馈链路、Fabric 的游戏内二维码和连接帮助。分支存在相同文件名不代表 handler 已接入相同调度逻辑。
4. **完成真正的波形设置。** 先提供事件到波形的选择和可用的导入/校验入口；当前空按钮和已完成的预览功能容易让用户误解进度。
5. **让关闭反馈的配置严格生效。** 核查所有最低强度 1 的截断，增加明确的关闭语义及“仅受伤”预设，避免用户逐项调零后仍有输出。
6. **更新介绍与下载导航。** 修正当前 README 的分支/版本信息，移除视频简介中无法找到附件的 Fabric 1.21.4 声明，说明 1.21.11 已有适配但 Fabric 有待修问题。

以上是根据现有反馈的影响范围提出的维护顺序，不是评论投票结果。独立中转程序、基岩版和新游戏接入属于更大范围的新增产品能力。
